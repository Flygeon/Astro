# 2026-08-01

## 集成 MusicPlayer 到博客 /music 页面

完成了将开源 MusicPlayer（Mengobs/MusicPlayer，MIT，作者 Meng Xinhong）改造为 Astro 博客的 `/music` 页面，并通过导航栏音乐按钮进入。

### 新增/修改文件
- 新增 `src/components/music/MusicPlayer.svelte`：原生 HTML/JS 重写为 Svelte 5（`client:only="svelte"`），保留原作者署名注释；通过 Meting API (`https://meting.mikus.ink/api?server=netease&type=playlist&id=18117338659`) 拉歌单。
- 新增 `src/pages/music.astro`：MainGridLayout + 构建期预取歌单兜底 + 原项目 MIT 署名区块。
- 新增 `src/types/music.ts`（Song/LyricLine/PlayMode 类型）。
- 新增 `public/music/default.svg`（封面兜底）。
- 新增 `THIRD-PARTY-NOTICES.md`（第三方开源声明 + MIT 全文 + 本站修改说明 + 数据版权）。
- 修改 `src/types/config.ts`（LinkPreset.Music=5）、`src/constants/link-presets.ts`、`src/i18n/i18nKey.ts`、`src/config.ts`、`src/components/Navbar.astro`（图标 `material-symbols:library-music-outline-rounded`）、10 个 i18n 语言文件。

### 关键技术修正
- Svelte 编译 CSS tree-shaking 会裁掉仅由 JS `classList.toggle("is-active")` 添加的歌词高亮样式：改为模板里 `class:is-active={i === activeLyric}` 声明，并移除 JS toggle。已 `astro build` 验证 `dist/_astro/*.css` 含 `.mp-lyric-line.is-active`。
- 原项目误用不存在的 CSS 变量 `--deep-text`/`--content-meta`，已替换为 `--content-text`/`--content-muted`。
- `onDestroy` 清空 `audioEl.src=""` 触发 error 误报：新增 `destroyed` 标志在 `handleError` 短路返回。
- 构建期沙箱批量删除保护拦截（50 文件阈值）非真实错误，`astro build` 实际成功。

### 验证结果
- `astro build` 成功，产出 `dist/music/index.html`、`dist/music/default.svg`。
- 构建产物含 `/music/` 链接（桌面 + 移动菜单各一处），导航图标 `library-music-outline-rounded` 就位。
- 音乐页面含 MIT 署名（Meng Xinhong / MusicPlayer / MIT License / meting.mikus.ink）。
